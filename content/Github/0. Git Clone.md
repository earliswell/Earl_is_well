## 깃 클론하기
 ```
 git clone <주소>
```

## 깃 remote
```
# 변수에 주소를 넣는 개념
git remote

# remote origin 변수 삭제
git remote remove origin

# origin 변수에 새로운주소 입력
git remote add origin <주소>
```

## 깃 푸쉬하기
```
# 처음 집어넣는 경우
git commit -m "init:  제목"

# 추가하는 경우
git commit -m "add: 제목"

# 삭제하는 경우
git commit -m "del: 제목"

# 변경하는 경우
git commit -m "modify: 제목"

# 고치는 경우 (에러)
git commit -m "fix: 제목"

# 전 커밋과 합침(파일 하나를 빠졌을 때), 커밋 내용 고치고 싶므연 --no-edit 삭제
git commit --amend --no-edit

# 최종, -f(강제 옵션 ㅋ)
git push -f 
```
