## Problem

A company's executives are interested in seeing who earns the most money in each of the company's departments. A **high earner** in a department is an employee who has a salary in the **top three unique** salaries for that department.

Write a solution to find the employees who are **high earners** in each of the departments.

Return the result table **in any order**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def top_three_salaries(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
	
	df = pd.merge(department, employee, how='outer', left_on='id', right_on='departmentId')
	df.drop(['id_x', 'id_y', 'departmentId'], axis=1, inplace=True)
	df.rename(columns={'name_x':'Department', 'name_y':'Employee'}, inplace=True)
	df.sort_values(['Department', 'salary'], ascending=[True, False], inplace=True)
	df['rank'] = df.groupby(['Department'], as_index=False)['salary'].rank(method='dense', ascending=False)
	
	return df[df['rank'] <= 3].iloc[:, :3]
```
