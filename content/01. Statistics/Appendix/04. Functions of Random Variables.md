## Introduction
- The objective of statistics is to make inferences about a population based on information contained in a sample taken from that population.
- 우리는 잊지 말아야 한다. 통계의 목적은 Sample로 부터 Population을 추론하는 것을 목적으로 둔다.
	- Population mean, $E(Y) = \mu$를 추론하기 위해 우리는 Sample mean $\bar{y}=\frac{1}{n}\sum_i^ny_i$을 활용한다.

## [[The method of distribution functions]]
- If Y has probability density function $f(y)$ $\to$ continuous and if $U$ is some function of Y. then we can find $F_U(u) = P(U \leq u)$ directly by integrating $f(y)$ over the region for which $U \leq u$.
- 원래의 확률 변수에 Y의 정의역이 새로운 함수 U에 대해서 "재구성"된다고 이해를 하면 좋다. 
	- 주의해야할 점 
		- U의 함수 형태에 따라 적분 영역이 하나가 아닐 수 있다.
		- Y의 정의역이 U로 변환될 때 일대일 대응이 아닐 수 있다. 마치, $Y^2$인 경우
		- 변환 후의 영역이 원래 Y의 정의역보다 작아질 수 있다. 

**Summary**
- Let U be a function of random variable $Y_1, Y_2, \dots, Y_n$.
	1. Find the region $U=u$ in the $(y_1, y_2, \dots, y_n)$ space. $\to$ U의 벙뮈를 결정
	2. Find the region $U\leq u$. $\to$ 정의역 업데이트
	3. Find $F_U(u) = P(U \leq u)$ by integrating $f(y_1, y_2, \dots, y_n)$ over the region $U \leq u$ $\to$ CDF 계산
	4. Find the density function $F_U(u)$ by differentiating $F_U(u)$. Thus, $F_U(u) = dF_U(u)/du$ $\to$ PDF 도출
- 이 과정은 고차원의 확률변수들의 함수를 단일 확률 변수로 "압축"하는 과정으로 이해를 하면 좋다. 기존 확률변수의 공간에서 $U$의 공간으로 "매핑"하는 것.
- 따라서 이 매핑된 공간에 따라 정의역의 모양이 완전이 변경될 수 있음.
- 이러한 이해를 통해서 다변수 확률변수의 변환이나 통계량(statistics)의 분포를 구할 때 매우 중요하다.
	- 예를 들어, 표본분산이나 카이제곱 통계량과 같은 복잡한 통계량의 분포를 유도할 때 이 방법이 핵심적으로 사용됨.

1. **표본분산 (Sample Variance)** : 표본 분산 $S^2$는 다음과 같이 정의된다.$$S^2=\frac{1}{n-1}\sum_i^n(X_i-\bar{X})^2$$$X_i \sim N(\mu, \sigma^2)$ 일 때, 위 개념을 적용해보자면 
	1. 먼저 $Z_i = (X_i \mu) / \sigma$로 변환 $Z \sim N(0,1)$ 
	2. Statistics : $\frac{(n-1)S^2}{\sigma^2} = \sum_i^k (Z_i-\bar{Z})^2$
	3. n차원의 공간에서 정의된 함수를 1차원으로 변환하는 과정
	4. 이는 결국 Dof(Degree of Freedom)이 n-1인 $\chi^2$를 따른다는 것을 증명함.
