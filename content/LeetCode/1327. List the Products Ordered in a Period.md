## Problem

Write a solution to get the names of products that have at least `100` units ordered in **February 2020** and their amount.

Return the result table in **any order**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def list_products(products: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
	
	orders = orders[(orders['order_date'] >= "2020-02") & (orders['order_date'] < "2020-03")]
	df_group = orders.groupby(['product_id'], as_index=False)[['unit']].sum()
	return products[['product_id', 'product_name']].merge(df_group[df_group['unit'] >= 100])[['product_name', 'unit']]
```
