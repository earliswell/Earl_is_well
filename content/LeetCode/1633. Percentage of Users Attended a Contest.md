## Problem

Write a solution to find the percentage of the users registered in each contest rounded to **two decimals**.

Return the result table ordered by `percentage` in **descending order**. In case of a tie, order it by `contest_id` in **ascending order**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def users_percentage(users: pd.DataFrame, register: pd.DataFrame) -> pd.DataFrame:
	total_len = len(users)
	
	new_df = register.groupby(['contest_id'])[['user_id']].count().reset_index()
	new_df['percentage'] = (new_df['user_id']/total_len * 100).round(2)
	
	return new_df.sort_values(['percentage', 'contest_id'], ascending=[False, True])[['contest_id', 'percentage']]
```
