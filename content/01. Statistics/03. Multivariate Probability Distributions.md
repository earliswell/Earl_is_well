## Bivariate and Multivariate Probability Distributions
- Bivariate : 두 개의 확률 변수를 동시에 고려하는 분포![[Pasted image 20241123140630.png]]
	- 예를 들어, 동전의 앞 뒤를 예로 들었을 때
		- 1. 첫 동전의 결과 (H, T) 
		- 2. 동전의 결과 (H, T)
		- 총 4가지의 경우의 수가 존재
- Multivariate : 셋 이상의 확률 변수를 동시에 고려하는 분포이다.
	- 위와 같은 예를 들자면, 총 3번 이상의 동전을 던져 나오는 경우의 확률분포 표를 의미한다.

**DEFINITION 5.1**
- Let $Y_1$ and $Y_2$ be discrete random variables. The joint (or bivariate) probability function for $Y_1$ and $Y_2$ is given by $p(y_1, y_2) = P(Y_1=y_1, Y_2=y_2), \qquad -\infty < y_1 < \infty, \, -\infty < y_2 < \infty.$

**THEOREM 5.1**
- If $Y_1$ and $Y_2$ are discrete random variables with joint probability function $p(y_1, y_2), then
	1. $p(y_1, y_2) \geq 0$ for all $y_1, y_2$
	2. $\sum_{y_1, y_2} p(y_1, y_2) = 1$, where the sum is over all values $(y_1, y_2)$ that are assigned nonzero probabilities.

- As in the univariate discrete case, the joint probability function for discrete random variables is sometimes called the joint probability mass function.
	- univariate discrete case : 일변량 이산형 확률분포
		- 단일 변수 (한 개의 변수)를 다루는 경우이다. $\to$ 주사위 한 번 굴렸을 때 나오는 분포

**DEFINITION 5.2**
- For any random variables $Y_1$ and $Y_2$, the joint (bivariate) distribution function $F(y_1, y_2)$ is $F(y_1, y_2) = P(Y_1 \leq y_1, Y_2 \leq y_2), \qquad -\infty<y_1<\infty, \, -\infty<y_2<\infty.$
	- for Discrete Case.$$F(y_1, y_2) = \sum_{t_1\leq y_1}\sum_{t_2 \leq y_2}p(t_1, t_2)$$
	- For Continuous Case.$$F(y_1, y_2) = \int_{-\infty}^{y_1}\int_{-\infty}^{y_2}f(t_1,t_2)dt_2dt_1$$
	- for all $-\infty < y_1 < \infty, \, -\infty < y_2 < \infty$
- then $Y_1$ and $Y_2$ are said to be jointly continuous random variables. the function $f(y_1, y_2)$ is called the joint probability density function.

**THEOREM 5.2**
- If $Y_1$ and $Y_2$ are random variables with joint distribution function $F(y_1, y_2)$, then 
	1. $F(-\infty, -\infty) = F(-\infty, y_2) = F(y_1, -\infty) = 0$
	2. $F(\infty, \infty) = 1$
		- $F(\infty, \infty) \equiv \lim_{y_1\to\infty}\lim_{y_2\to\infty}F(y_1, y_2) = 1$
	3. if $y_1^* \geq y_1$ and $y_2^* \geq y_2$, then $F(y_1^*, y_2^*) - F(y_1^*, y_2) - F(y_1, y_2^*) + F(y_1, y_2) \leq 0.$ ![[Pasted image 20241123143756.png]]
- 위 1번 특징은 CDF의 특징을 이해하면 쉽다. Joint CDF에서 한 변수가 음의 무한대의 수라면, 이는 다른 변수가 아무리 특정 수를 갖는다고 해도 우리는 어떠한 누적 값을 획득할 수 없다. 
	- 예를 들어 Discrete Case에서, $F(-\infty, y_2) = \sum_{t_1\leq -\infty}\sum_{t_2 \leq y_2}p(t_1, t_2) = 0$인 것 처럼, 일 변수가 음의 무한대인 경우는 존재하지 않음. 
	- 이와 더불어 Continuous Case에서도 $\int_{-\infty}^{-\infty}$인  상한과 하한이 같은 경우의 적분 값은 0이된다. 

**THEOREM 5.2**
- If $Y_1$ and $Y_2$ and jointly continuous random variables with a joint density function given by $f(y_1, y_2)$, then
	1. $f(y_1, y_2) \geq 0$ for all $y_1, y_2$
	2. $\int_{-\infty}^{\infty}\int_{-\infty}^{\infty}f(y_1, y_2)dy_1dy_2 = 1$

## Marginal and Conditional Probability Distributions
- 우리가 주사위를 2번 던지는 경우에 대해서 생각해보자
	- $Y_1 =$ Number of dots on the upper face of die 1
	- $Y_1 =$ Number of dots on the upper face of die 2
	- 이는 각 케이스에서 주사위를 굴렸을 때 하늘을 바라보는 수를 의미한다.

- 그렇다면 $P(Y_1 = y_1) = p_1(y_1)$은 어떻게 구할 수 있을까?
	- 답은 $\sum_{y_2=1}^6 p(y_1, y_2)$이다. 즉, 한 변수를 고정한 후 나머지 경우 확률을 더해주면 된다.
		- y_1이 1인 경우 : y_1이 1이면서 y_2의 범위가 1부터 6까지의 모든 경우의 확률

- 한 축을 고정시켜 놓고 확률을 구할 수 있는데,
	- For Discrete case (Marginal Probability functions of $Y_1, Y_2$)$$p_1(y_1) = \sum_{\text{all}\,y_2}p(y_1, y_2) \qquad \text{and} \qquad p_2(y_2) = \sum_{\text{all}\,y_1}p(y_1,y_2)$$
	- For Continuous case (Marginal density functions of $Y_1, Y_2$)$$f_1(y_1) = \int_{-\infty}^\infty f(y_1, y_2)dy_2 \qquad \text{and} \qquad f_2(y_2) = \int_{-\infty}^{\infty}f(y_1, y_2)dy_1$$
- 우리는 $P(A)$를 unconditional of A 그리고 $P(B|A)$를 probability of B given that A. 즉, Conditional probability라고 부른다.

**DEFINITION 5.5**
- For Conditional Discrete Probability function of $Y_1$ given $Y_2$ $$p(y_1|y_2) = P(Y_1=y_1|Y_2=y_2) = \frac{P(Y_1=y_1, Y_2=y_2)}{P(Y_2 =y_2)} = \frac{p(y_1, y_2)}{p_2(y_2)}$$
	- provided that $p_2(y_2) > 0$

- For Conditional Distribution function(jointly continuous random variable with joint density function) of $Y_1$ given $Y_2 =y_2$ $$F(y_1|y_2) = P(Y_1 \leq y_1|Y_2=y_2)$$
	- $F(y_1) = \int_{-\infty}^\infty F(y_1|y_2)f_2(y_2)dy_2$
		- = $\int_{-\infty}^{y_1}f_1(t_2)dt_1 = \int_{-\infty}^{y_1}\left[\int_{-\infty}^\infty f(t_1, y_2)dy_2\right]dt_1$
		- = $\int_{-\infty}^{\infty}\int_{-\infty}^{y_1}f(t_1, y_2)dt_1dy_2.$
	- $F(y_1|y_2)f_2(y_2) = \int_{-\infty}^{y_1}f(t_1,y_2)dt_1$
		- $F(y_1|y_2) = \int_{-\infty}^{y_1}\frac{f(t_1, y_2)}{f_2(y_2)}dt1.$

- 식을 전개했을 때 ![[Pasted image 20241123154624.png]]
	- 적분 순서를 변경해도 상관 없음 !
	- 주의해야하는 경우
		1. 적분 범위가 변수의 의존할 때
		2. 불연속점이 있는 경우
		3. 무한대 적분의 경우 수렴성을 확인할 필요가 있음.

**DEFINITION 5.7**
- Let $Y_1$ and $Y_2$ be jointly continuous random variables with joint density $f(y_1, y_2)$ and marginal densities $f_1(y_1)$ and $f_2(y_2)$, respectively. For any $y_2$ such that $f_2(y_2) >0$, the conditional density of $Y_1$ given $Y_2 = y_2$ is given by$f(y_1|y_2) = \frac{f(y_1, y_2)}{f_2(y_2)}$ and for any $y_1$ such that $f_1(y_2) > 0$, the conditional density of $Y_2$ given $Y_1=y_1$ is given by $f(y_2|y_1)=\frac{f(y_1, y_2)}{f_1(y_1)}$

- 항상 분모가 0이 되는 Case를 유의해야한다.
