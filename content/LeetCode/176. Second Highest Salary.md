## Problem

Write a solution to find the second highest **distinct** salary from the `Employee` table. If there is no second highest salary, return `null (return None in Pandas)`.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def second_highest_salary(employee: pd.DataFrame) -> pd.DataFrame:
	
	df = employee.sort_values(by='salary', ascending=False).drop_duplicates(subset=['salary'], keep='first')
	
	if df['salary'].nunique() < 2:
		salary = pd.DataFrame({'SecondHighestSalary': [pd.NA]})
	
	else:
		second_salary = df.iloc[1, 1]
		salary = pd.DataFrame({'SecondHighestSalary':[second_salary]})
	
	return salary
```
