1. Univariate (일변량) 예시:
   - 주사위 하나를 던질 때
   $$X_1 \in \{1,2,3,4,5,6\}$$
   - 확률분포:
   $$P(X_1 = i) = \frac{1}{6}, \text{ for } i \in \{1,2,3,4,5,6\}$$

   - 동전 한 번 던질 때
   $$X_1 \in \{H,T\}$$
   - 확률분포:
   $$P(X_1 = H) = \frac{1}{2}, P(X_1 = T) = \frac{1}{2}$$

2. Bivariate (이변량) 예시:
   - 주사위 두 개를 동시에 던질 때
   $$X_1, X_2 \in \{1,2,3,4,5,6\}$$
   - 결합확률분포(Joint Distribution):
   $$P(X_1 = i, X_2 = j) = \frac{1}{36}$$
   여기서 i, j는 각각 1부터 6까지의 값

   - 동전 두 개를 동시에 던질 때
   $$X_1, X_2 \in \{H,T\}$$
   - 결합확률분포:
   $$P(X_1 = i, X_2 = j) = \frac{1}{4}$$
   여기서 i, j는 각각 H 또는 T

주요 차이:
1. 변수의 수
   - Univariate: 단일 변수 $X_1$
   - Bivariate: 두 변수 $(X_1, X_2)$

2. 확률 계산
   - Univariate: $P(X_1)$만 고려
   - Bivariate: 
     - 결합확률 $P(X_1, X_2)$
     - 조건부확률 $P(X_1|X_2)$ 또는 $$P(X_2|X_1)$$
     - 주변확률 $P(X_1) = \sum_{x_2} P(X_1, X_2)$

3. 분석 가능한 특성
   - Univariate: 개별 변수의 특성만 분석
   - Bivariate: 두 변수 간의 관계와 상호작용도 분석 가능

이처럼 univariate는 단일 변수의 분포를, bivariate는 두 변수의 결합분포를 다루는 것이 핵심 차이
