## Problem

Write a solution to find the prices of all products on `2019-08-16`. Assume the price of all products before any change is `10`.

Return the result table in **any order**.

## My Answer.
```python
import pandas as pd

  

def price_at_given_date(products: pd.DataFrame) -> pd.DataFrame:
	
	target_data = pd.to_datetime('2019-08-16')
	valid_change = products[products['change_date'] <= target_data]
	latest_prices = (valid_change.sort_values('change_date', ascending=False)
	.groupby('product_id')
	.first()
	.reset_index()[['product_id', 'new_price']])
	
	all_product = pd.DataFrame({'product_id': products['product_id'].unique()})
	result = (all_product.merge(latest_prices, on='product_id', how='left')
	.rename(columns={"new_price": 'price'})
	.fillna({'price': 10}))
	
	return result
```
