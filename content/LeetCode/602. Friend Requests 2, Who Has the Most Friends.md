## Problem

Write a solution to find the people who have the most friends and the most friends number.

The test cases are generated so that only one person has the most friends.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def most_friends(request_accepted: pd.DataFrame) -> pd.DataFrame:
	
	# requester_id 기준으로 그룹화
	df_1 = request_accepted.groupby(['requester_id'], as_index=False)[['accepter_id']].count().rename(columns={"requester_id":'id','accepter_id':'num'})
	
	# accepter_id 기준으로 그룹화
	df_2 = request_accepted.groupby(['accepter_id'], as_index=False)['requester_id'].count().rename(columns={'accepter_id':'id', 'requester_id':'num'})
	
	# 두 데이터프레임을 합치고 친구 수 합산
	final = pd.concat([df_1, df_2]).groupby('id', as_index=False)['num'].sum()
	
	# 가장 많은 친구를 가진 사람 반환
	return final[final['num'] == final['num'].max()].sort_values('id')
```
