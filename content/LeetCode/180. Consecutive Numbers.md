## Problem

Find all numbers that appear at least three times consecutively.

Return the result table in **any order**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
	
	logs['num_1'] = logs['num'].shift(1)
	logs['num_2'] = logs['num_1'].shift(1)
	
	return logs[(logs['num'] == logs['num_1']) & (logs['num'] == logs['num_2'])]['num'].to_frame().rename(columns={'num':'ConsecutiveNums'}).drop_duplicates()
```


### Other Answer

1. window 함수를 사용한 방법:
```python
def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    # rolling window를 사용해 연속된 3개의 값이 같은지 확인
    mask = logs['num'].rolling(window=3).apply(lambda x: len(set(x)) == 1)
    result = logs[mask]['num'].drop_duplicates()
    return pd.DataFrame({'ConsecutiveNums': result})
```

2. groupby와 count를 활용한 방법:
```python
def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    # 연속된 같은 숫자를 그룹화
    logs['group'] = (logs['num'] != logs['num'].shift()).cumsum()
    
    # 각 그룹의 크기를 계산
    consecutive = logs.groupby(['group', 'num']).size().reset_index(name='count')
    
    # 3번 이상 연속된 숫자만 선택
    result = consecutive[consecutive['count'] >= 3]['num'].drop_duplicates()
    return pd.DataFrame({'ConsecutiveNums': result})
```

3. 리스트 컴프리헨션을 사용한 방법:
```python
def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    nums = logs['num'].tolist()
    consecutive = {nums[i] for i in range(len(nums)-2) 
                  if nums[i] == nums[i+1] == nums[i+2]}
    return pd.DataFrame({'ConsecutiveNums': list(consecutive)})
```

4. merge를 사용한 방법:
```python
def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    # 같은 데이터프레임을 index를 하나씩 밀어서 병합
    df1 = logs.copy()
    df2 = logs.copy().set_index(logs.index + 1)
    df3 = logs.copy().set_index(logs.index + 2)
    
    merged = df1.merge(df2, left_index=True, right_index=True, suffixes=('', '_2'))
    merged = merged.merge(df3, left_index=True, right_index=True, suffixes=('', '_3'))
    
    result = merged[
        (merged['num'] == merged['num_2']) & 
        (merged['num'] == merged['num_3'])
    ]['num'].drop_duplicates()
    
    return pd.DataFrame({'ConsecutiveNums': result})
```

각 방법의 특징:

1. rolling 방법: 
   - 코드가 간결하고 직관적
   - pandas의 내장 함수를 활용해 효율적
   - 메모리 사용이 효율적

2. groupby 방법:
   - 더 복잡한 패턴 분석에도 확장 가능
   - 연속된 숫자의 개수를 쉽게 파악 가능
   - 추가 분석이 필요할 때 유용

3. 리스트 컴프리헨션 방법:
   - 가장 직관적이고 이해하기 쉬움
   - 작은 데이터셋에 적합
   - 순수 Python 스타일의 해결방법

4. merge 방법:
   - SQL 스타일의 접근방식
   - 복잡한 조인 조건이 필요한 경우에도 확장 가능
   - 다른 테이블과의 조인이 필요한 경우 유용
