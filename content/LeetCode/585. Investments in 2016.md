## Problem

Write a solution to report the sum of all total investment values in 2016 `tiv_2016`, for all policyholders who:

- have the same `tiv_2015` value as one or more other policyholders, and
- are not located in the same city as any other policyholder (i.e., the (`lat, lon`) attribute pairs must be unique).

Round `tiv_2016` to **two decimal places**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def find_investments(insurance: pd.DataFrame) -> pd.DataFrame:
	
	# 동일 집단 제거
	resq = insurance.drop_duplicates(subset=['lat', 'lon'], keep=False)
	
	# tiv_2015를 기준으로 pid count
	need = insurance.groupby('tiv_2015').pid.count().reset_index()
	
	# pid가 2 이상인 dataframe 추출
	need = need[need['pid'] >= 2]
	
	# pid를 1로 변환
	need['pid'] = 1
	
	# pid -> coef 변환하여 결측값 0으로 처리
	resq = resq.merge(need.rename(columns={'pid' : 'coef'})).fillna(0)[['tiv_2016', 'coef']]
	
	# 'coef'와 'tiv_2016'을 곱함
	resq['tiv_2016'] *= resq['coef']
	
	return pd.DataFrame([resq['tiv_2016'].sum()], columns=['tiv_2016']).round(2)
```
