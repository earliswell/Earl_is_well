## Problem

Write a solution to calculate the number of unique subjects each teacher teaches in the university.

Return the result table in **any order**.

The result format is shown in the following example.

## My Answer.
```python
import pandas as pd

def count_unique_subjects(teacher: pd.DataFrame) -> pd.DataFrame:
	
	return teacher.groupby('teacher_id')[['subject_id']].nunique().reset_index().rename(columns={'subject_id': 'cnt'})
```

# pandas의 nunique() 함수

## 기본 개념
`nunique()`는 pandas에서 고유한(unique) 값의 개수를 계산하는 함수입니다. Series나 DataFrame에서 사용할 수 있으며, 결측값(NA)은 기본적으로 제외됩니다.

## 기본 문법
```python
# Series에서 사용
Series.nunique(dropna=True)

# DataFrame에서 사용
DataFrame.nunique(axis=0, dropna=True)
```

## 주요 매개변수
- `dropna` (bool, default=True)
  - True: NA/null 값을 제외하고 계산
  - False: NA/null 값을 포함하여 계산
- `axis` (0 or 1, default=0)
  - 0: 각 열(column)의 고유값 개수 계산
  - 1: 각 행(row)의 고유값 개수 계산

## 사용 예시

### 1. Series에서의 기본 사용
```python
import pandas as pd

s = pd.Series([1, 2, 2, 3, 3, 3, 4, None])
print(s.nunique())  # 출력: 4 (기본적으로 None 제외)
print(s.nunique(dropna=False))  # 출력: 5 (None 포함)
```

### 2. DataFrame에서의 기본 사용
```python
df = pd.DataFrame({
    'A': [1, 2, 2, 3, 3],
    'B': [1, 1, 2, 2, 3],
    'C': [1, 1, 1, 2, 2]
})

# 각 열의 고유값 개수
print(df.nunique())
# 출력:
# A    3
# B    3
# C    2
```

### 3. groupby와 함께 사용
```python
df = pd.DataFrame({
    'group': ['A', 'A', 'B', 'B', 'B'],
    'value': [1, 2, 2, 3, 3]
})

# 그룹별 고유값 개수
print(df.groupby('group')['value'].nunique())
# 출력:
# group
# A    2
# B    2
```

### 4. 여러 열에 대한 고유값 계산
```python
df = pd.DataFrame({
    'teacher_id': [1, 1, 1, 2, 2],
    'subject_id': [101, 102, 101, 103, 104],
    'class_id': [1, 2, 3, 4, 5]
})

# 교사별 고유 과목 수와 클래스 수 계산
result = df.groupby('teacher_id')[['subject_id', 'class_id']].nunique()
print(result)
# 출력:
# teacher_id  subject_id  class_id
# 1          2          3
# 2          2          2
```

## 주의사항
1. NA/null 값 처리에 주의가 필요합니다.
2. groupby 연산 후 nunique를 사용할 때는 집계하려는 열을 리스트로 묶어야 합니다.
3. 대용량 데이터에서는 메모리 사용량에 주의해야 합니다.

## 활용 팁
1. reset_index()와 함께 사용하여 결과를 보기 좋게 만들 수 있습니다.
2. rename()을 통해 결과 열의 이름을 변경할 수 있습니다.
3. 여러 열에 대해 동시에 고유값을 계산할 수 있습니다.

```python
# 예시: 모든 기능 활용
result = (df.groupby('teacher_id')[['subject_id', 'class_id']]
          .nunique()
          .reset_index()
          .rename(columns={
              'subject_id': 'unique_subjects',
              'class_id': 'unique_classes'
          }))
```

이러한 nunique() 함수는 데이터 분석에서 중복 제거된 값의 개수를 계산할 때 매우 유용하게 사용됩니다.
