## Problem

Write a solution to report the **fraction** of players that logged in again on the day after the day they first logged in, **rounded to 2 decimal places**. In other words, you need to count the number of players that logged in for at least two consecutive days starting from their first login date, then divide that number by the total number of players.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def gameplay_analysis(activity: pd.DataFrame) -> pd.DataFrame:
	
	# 1. 각 플레이어의 첫 로그인 날짜 찾기
	first_login = activity.groupby('player_id')['event_date'].min().reset_index(
	first_login.columns = ['player_id', 'first_login']
	
	# 2. 원본 데이터와 병합
	activity = activity.merge(first_login, on='player_id')
	
	# 3. 첫 로그인과의 차이만 계산
	activity['days_after_first'] = (activity['event_date'] - activity['first_login']).dt.days
	
	# 4. 첫 로그인 다음날 로그인한 유저 수
	after_login = len(activity[activity['days_after_first'] == 1]['player_id'].unique())
	
	# 5. 전체 유저 수
	unique_id = len(activity['player_id'].unique())

	return pd.DataFrame({"fraction": [round(after_login / unique_id, 2)]})
```
