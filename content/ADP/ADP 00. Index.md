### 주요 내용

데이터분석 실무

### 출제 방향

기계학습 영역과 통계 영역으로 출제된다.

#### 기계학습

기계학습 영역은 ‘기계학습 알고리즘을 활용한 분석’, ‘통계적 학습 방법을 활용한 분석’을 포괄하며, 데이터 전처리 및 탐색적 데이터 분석, 모델링 및 결과 해석 과정을 포함한다.
##### 기계학습 알고리즘을 활용한 분석
###### **유형1 :** 데이터 전처리
결측값 처리, 이상값 탐지 및 수정, 데이터 정규화, 파생 변수 생성, 데이터 샘플링, 데이터 병합 및 분할 작업 등 데이터의 질을 향상시키고 모델링에 적합한 형태로 변환하는 작업이 포함된다.
###### **유형2 :** 탐색적 데이터 분석(EDA)
요약 통계량 계산을 통한 기초 통계 분석, 히스토그램, 산점도, 상자그림 등을 이용한 데이터 시각화, 주요 변수 간의 관계 분석, 차원 축소 기법, 군집 분석 등을 통해 데이터의 분포 및 군집 구조를 파악하고 주요 패턴을 도출하는 작업이 포함된다.
###### **유형3 :** 기계학습 알고리즘을 활용한 모델 구축
회귀, 분류, 군집화 등의 다양한 분석 기법을 선택하여 적용하고, 초매개변수(hyperparameter) 조율을 통해 모델 성능을 최적화하는 작업이 포함된다.
###### **유형4 :** 구축한 모델을 평가하고 최적의 모델을 선택
다양한 지표로 모델 성능을 평가하고 결과를 해석하여, 최적의 모델을 선정하는 등의 작업이 포함된다.
##### 통계적 학습 방법을 활용한 분석

###### **유형1 :** 데이터 품질 평가 및 변수 선택·처리
이상값 및 결측값 처리, 변수 구성 및 기초통계량 산출, 연속형 및 범주형 변수에 대한 기초적인 통계 검정 등 데이터 품질을 평가하고 변수를 적절하게 처리하는 작업이 포함된다.

###### **유형2 :** 변수 간 관계 분석 및 예측 모델 구축
독립변수와 종속변수 간의 관계를 통계적 기법을 통해 분석하고, 데이터를 변형하여 모델 성능을 향상시키며, 그 결과를 통해 유의미한 통찰을 도출하는 작업이 포함된다.

###### **유형3 :** 통계적 학습 방법 및 기계학습 방법을 사용한 모델 구축
통계적 학습 방법과 기계학습 방법으로 모델을 구축하여 각 방법론을 비교하고 최적의 모델을 선정하는 등의 작업이 포함된다.

#### 통계

통계 영역은 ‘데이터 탐색 및 기초 통계 분석’,‘통계적 추론 및 통계 모형 구축’등을 포괄한다.

##### 데이터 탐색 및 기초 통계 분석
###### **유형1 :** 기술통계량 계산 및 시각화
평균, 중앙값, 분산 표준편차 등의 기술 통계량을 계산하고, 히스토그램, 산점도, 상자그림 등 시각화 기법을 사용하여 데이터의 분포, 이상값, 패턴 등을 시각적으로 표현하는 등의 작업이 포함된다.
###### **유형2 :** 탐색적 데이터 분석(EDA) 및 데이터 전처리
EDA 과정에서 결측값 처리, 이상값 수정, 변수 변환 및 파생 변수 생성 등의 전처리 작업을 통해 데이터를 분석 및 준비하는 등의 작업이 포함된다.

  
##### 통계적 추론 및 통계 모형 구축
###### **유형1 :** 통계적 유의성 검정
가설 검정 기법을 사용하여 데이터의 통계적 유의성을 검정하고, 신뢰 구간을 계산하여 데이터의 불확실성을 평가하는 등의 작업이 포함된다.

###### **유형2 :** 상관 분석 및 회귀 분석
상관 분석을 통해 변수 간의 연관성을 파악하고, 단순 및 다중 선형 회귀, 로지스틱 회귀, 비선형 회귀 모델 등을 구축하여 데이터 간의 관계를 분석하고 예측 모델을 평가하는 작업이 포함된다.

###### **유형3 :** 다변량 분석
고차원 데이터에서 중요한 정보를 추출하고 데이터의 차원을 축소하거나 변수 간의 관계를 분석하고, 그룹 간의 차이를 분석·분류하여 군집화하는 등의 작업이 포함된다.
###### **유형4 :** 시계열 분석
시계열 데이터를 분석하여 추세, 계절성, 변동성을 반영하는 예측 모델 구축 및 미래 데이터를 예측하고, 데이터를 시각화하며, 적절한 모델을 사용해 예측 성능을 평가하는 작업이 포함된다.

###### **유형5 :** 고급 통계 분석
고급 통계 기법을 선택·적용하여 데이터의 특성을 분석하고, 도출된 결과를 해석하는 등의 작업이 포함된다.

  
### 고려사항
데이터 분석 실기 문제의 답안을 작성할 때는 다음의 사항에 유의해야 한다.

###### 명확한 표현과 논리적 전개
답안은 주어진 문제에 대한 핵심 내용만을 명확하고 간결하게 작성하며, 분석 과정과 결론에 일관성이 있어야 한다. 해당 문제와 관련된 분석 방법론과 데이터 특성을 반영하여 논리적으로 전개해야 하며, 이해하기 쉽게 작성되었는지 검토한다.

###### 분석 절차와 코드 서술
데이터 전처리, 모델링, 검정 절차 등 분석 과정의 각 단계와 관련된 코드를 간결하게 정리하여 제출한다. 코드의 효율성과 정확성을 유지하며, 주요 부분에 대해 주석을 통해 설명을 추가하고, 코드의 각 부분이 해당 문제 풀이에 어떻게 연결되는지를 명확히 나타낸다.

###### 데이터 전처리와 탐색적 분석(EDA)
데이터 전처리 과정에서 수행한 결측값 처리, 이상값 수정, 변수 변환 등의 작업 내용을 기술하고 해당 과정이 분석에 미친 영향 등을 설명한다. 탐색적 데이터 분석 결과는 시각화 자료와 함께 제시하고 파악된 데이터의 기본 특성 등을 설명한다.

###### 모델 선택
사용한 분석 기법 또는 모델을 선택한 이유와 그 과정에서 고려한 대안들을 서술하고, 선택한 모델이 문제 해결에 어떻게 기여했는지 논리적으로 설명한다. 다양한 모델 중에서 선택한 이유와 해당 모델의 강점, 잠재적 한계점 등을 명확히 기술하며, 다른 방법들과의 비교를 통해 선택의 정당성을 입증한다.

###### 결과 해석
분석 결과의 실질적 유용성을 바탕으로 최종 결론을 도출하고 분석 내용을 종합적으로 요약하며, 추가적인 제언 등을 기술한다.

## 5. 데이터 전처리 방향 설정하기

```python
# 결측치 처리 방향
for col in df.columns[df.isnull().sum() > 0]:
    if col in df.select_dtypes(include=['int64', 'float64']).columns:
        print(f"{col}: Consider using mean/median imputation")
    else:
        print(f"{col}: Consider using mode imputation or creating a 'Missing' category")

# 이상치 처리 방향
for col in df.select_dtypes(include=['int64', 'float64']).columns:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    outliers = df[(df[col] < Q1 - 1.5 * IQR) | (df[col] > Q3 + 1.5 * IQR)][col]
    if len(outliers) > 0:
        print(f"{col}: {len(outliers)} outliers detected. Consider capping/flooring or transformation.")
```

## 2. 기초통계량과 확률분포

### 2.1 기초통계량 활용 전략

**핵심 통계량:**
- 중심경향: 평균, 중앙값, 최빈값
- 분산성: 분산, 표준편차, 범위, IQR
- 분포형태: 왜도(skewness), 첨도(kurtosis)

**데이터 특성에 따른 대표값 선택:**
- 정규분포에 가까운 데이터 → 평균
- 왜도가 큰 데이터 → 중앙값
- 이상치가 많은 데이터 → 중앙값, 절사평균(trimmed mean)

**코드 핵심:**
```python
# 기초통계량
summary = df.describe()
# 왜도와 첨도
skewness = stats.skew(data)
kurtosis = stats.kurtosis(data)
# 정규성 평가
if abs(skewness) < 0.5 and abs(kurtosis) < 0.5:
    print("Data is approximately normal")
```

### 2.2 확률분포 선택 가이드

**이항분포 vs 포아송분포:**
- 이항분포: 고정된 시행 횟수(n)에서 성공 횟수 (예: 100명 중 합격자 수)
- 포아송분포: 고정된 시간/공간에서 사건 발생 횟수 (예: 1시간당 고객 방문 수)
- n이 크고 p가 작을 때 이항분포 ≈ 포아송분포(λ=np)

**이항분포 vs 초기하분포:**
- 이항분포: 복원추출 또는 모집단이 매우 클 때
- 초기하분포: 비복원추출이며 모집단 크기가 유한할 때 (예: 30명 중 5명 추출)

**포아송분포 vs 지수분포:**
- 포아송분포: 단위 시간당 사건 발생 횟수
- 지수분포: 사건 간 시간 간격
- 관계: 포아송 과정에서 사건 발생 간격은 지수분포를 따름

**정규분포 근사:**
- 이항분포: n≥30, np≥5, n(1-p)≥5일 때 정규분포로 근사 가능
- 포아송분포: λ≥10일 때 정규분포로 근사 가능

**문제 유형에 따른 분포 선택:**
- 계수 데이터: 이항분포(크기 고정), 포아송분포(시간/공간 고정)
- 시간 데이터: 지수분포(대기시간), 와이블분포(수명 데이터)
- 측정 데이터: 정규분포(자연현상), 로그정규분포(양의 왜도)

## 3. 가설검정 마스터 플랜

### 3.1 검정 유형 선택 가이드

**변수 유형에 따른 선택:**
- 연속형 vs 연속형: 상관분석(Pearson, Spearman)
- 범주형 vs 범주형: 카이제곱 검정, 피셔의 정확검정
- 연속형 vs 범주형(2집단): t-검정, Mann-Whitney U 검정
- 연속형 vs 범주형(3집단+): 분산분석, Kruskal-Wallis 검정

**데이터 특성에 따른 선택:**
- 정규성 만족 → 모수적 검정(t-검정, ANOVA)
- 정규성 불만족 → 비모수 검정(Mann-Whitney, Wilcoxon)
- 대응 표본 → 대응표본 t-검정, 윌콕슨 부호순위 검정
- 독립 표본 → 독립표본 t-검정, Mann-Whitney U 검정

**표본 크기에 따른 고려사항:**
- 대표본(n≥30): 중심극한정리로 정규성 가정 완화 가능
- 소표본(n<30): 정규성 검정 중요, 비모수 검정 고려
- 매우 작은 표본: 정확검정(피셔의 정확검정) 고려

### 3.2 가설검정 프로세스

**1. 가설 설정:**
- 귀무가설(H₀): 차이/효과/관계가 없다
- 대립가설(H₁): 차이/효과/관계가 있다 (양측/단측)

**2. 검정 통계량 계산:**
- t-검정: t-통계량
- ANOVA: F-통계량
- 카이제곱: χ²-통계량
- 비모수: 순위합, 부호순위 등

**3. p-값 평가:**
- p < α → 귀무가설 기각
- p ≥ α → 귀무가설 채택(정확히는 '기각하지 못함')

**4. 효과 크기 해석:**
- Cohen's d, η², r, Cramer's V 등
- 통계적 유의성뿐만 아니라 실질적 중요성 고려

## 5. 상관분석과 회귀분석

### 5.1 상관분석 전략

**상관계수 선택:**
- 피어슨: 정규분포, 선형관계
- 스피어만: 비정규분포, 단조관계
- 켄달의 타우: 작은 표본, 동률 많음

**코드 핵심:**
```python
# 정규성 확인 후 상관계수 선택
if shapiro1.pvalue > 0.05 and shapiro2.pvalue > 0.05:
    # 정규성 만족 → 피어슨
    r, p = stats.pearsonr(x, y)
    print(f"Pearson r: {r:.4f}, p: {p:.4f}")
else:
    # 정규성 불만족 → 스피어만
    rho, p = stats.spearmanr(x, y)
    print(f"Spearman rho: {rho:.4f}, p: {p:.4f}")

# 작은 표본 또는 동률 많음
if n < 30 or has_many_ties:
    tau, p = stats.kendalltau(x, y)
    print(f"Kendall tau: {tau:.4f}, p: {p:.4f}")
```

**상관계수 해석:**
- 약함: |r| < 0.3
- 중간: 0.3 ≤ |r| < 0.5
- 강함: |r| ≥ 0.5

### 5.2 회귀분석 접근법

**회귀모형 구축 단계:**
1. 변수 간 관계 탐색(산점도, 상관분석)
2. 적절한 모형 선택(단순/다중/더미변수/교호작용)
3. 모형 적합 및 진단
4. 모형 개선 및 최종 선택

**회귀모형 진단:**
- 선형성: 잔차 vs 적합값 플롯
- 정규성: Q-Q 플롯, Shapiro-Wilk 검정
- 등분산성: Breusch-Pagan 검정
- 독립성: Durbin-Watson 검정
- 다중공선성: VIF(10 이상이면 문제)
- 영향점: Cook's distance

**코드 핵심:**
```python
# 회귀모형 구축
import statsmodels.api as sm
X = sm.add_constant(X)  # 상수항 추가
model = sm.OLS(y, X).fit()
print(model.summary())
```

### 8.1 정규성 및 등분산성 검정

```python
# 정규성 검정
def check_normality(data, alpha=0.05):
    # 시각적 검정
    plt.figure(figsize=(12, 4))
    plt.subplot(1, 2, 1)
    plt.hist(data, bins=15, alpha=0.7)
    plt.title('히스토그램')
    
    plt.subplot(1, 2, 2)
    stats.probplot(data, dist="norm", plot=plt)
    plt.title('Q-Q 플롯')
    plt.tight_layout()
    
    # 통계적 검정
    shapiro_test = stats.shapiro(data)
    print(f"Shapiro-Wilk 검정: 통계량={shapiro_test.statistic:.4f}, p값={shapiro_test.pvalue:.4f}")
    print(f"결론: {'정규성 가정 만족하지 않음' if shapiro_test.pvalue < alpha else '정규성 가정 만족'}")
    
    return shapiro_test.pvalue > alpha  # 정규성 만족 여부 반환

# 등분산성 검정
def check_homogeneity(group1, group2, alpha=0.05):
    levene_test = stats.levene(group1, group2)
    print(f"Levene 검정: 통계량={levene_test.statistic:.4f}, p값={levene_test.pvalue:.4f}")
    print(f"결론: {'등분산 가정 만족하지 않음' if levene_test.pvalue < alpha else '등분산 가정 만족'}")
    
    return levene_test.pvalue > alpha  # 등분산성 만족 여부 반환
```

### 8.2 두 집단 비교 검정
```python
def compare_two_groups(group1, group2, paired=False, alpha=0.05):
    # 대응표본 여부에 따라 정규성 검정
    if paired:
        diff = group1 - group2
        normality = check_normality(diff)
        if normality:
            # 대응표본 t-검정
            t_stat, p_value = stats.ttest_rel(group1, group2)
            test_name = "대응표본 t-검정"
        else:
            # 윌콕슨 부호순위 검정
            t_stat, p_value = stats.wilcoxon(group1, group2)
            test_name = "윌콕슨 부호순위 검정"
    else:
        # 독립표본: 두 집단 각각 정규성 검정
        norm1 = check_normality(group1)
        norm2 = check_normality(group2)
        
        if norm1 and norm2:
            # 등분산성 검정
            equal_var = check_homogeneity(group1, group2)
            # 독립표본 t-검정
            t_stat, p_value = stats.ttest_ind(group1, group2, equal_var=equal_var)
            test_name = "독립표본 t-검정" if equal_var else "Welch's t-검정"
        else:
            # Mann-Whitney U 검정
            t_stat, p_value = stats.mannwhitneyu(group1, group2, alternative='two-sided')
            test_name = "Mann-Whitney U 검정"
    
    print(f"\n{test_name} 결과:")
    print(f"통계량: {t_stat:.4f}, p값: {p_value:.4f}")
    print(f"결론: {'두 집단 간 차이가 있음' if p_value < alpha else '두 집단 간 차이가 없음'}")
    
    return test_name, t_stat, p_value
```

### 8.3 카이제곱 검정
```python
def chi_square_test(df, var1, var2, alpha=0.05):
    # 교차표 작성
    contingency_table = pd.crosstab(df[var1], df[var2])
    print("교차표:")
    print(contingency_table)
    
    # 기대빈도 계산 및 카이제곱 검정
    chi2, p, dof, expected = stats.chi2_contingency(contingency_table)
    
    # 기대빈도 확인
    print("\n기대빈도:")
    print(pd.DataFrame(expected, 
                      index=contingency_table.index, 
                      columns=contingency_table.columns))
    
    # 기대빈도 5 미만 셀 확인
    small_expected = (expected < 5).sum()
    small_expected_pct = small_expected / expected.size * 100
    
    if small_expected_pct > 20:
        print(f"\n주의: 기대빈도가 5 미만인 셀이 {small_expected_pct:.1f}%로, 20%를 초과합니다.")
        if contingency_table.shape == (2, 2):
            # 피셔의 정확검정(2x2 표만 가능)
            oddsratio, p_fisher = stats.fisher_exact(contingency_table)
            print("\n피셔의 정확검정 결과:")
            print(f"오즈비: {oddsratio:.4f}, p값: {p_fisher:.4f}")
            print(f"결론: {'두 변수 간 연관성이 있음' if p_fisher < alpha else '두 변수 간 연관성이 없음'}")
            return "피셔의 정확검정", p_fisher
        else:
            print("권장: 범주를 병합하거나 더 큰 표본을 수집하세요.")
    
    # 카이제곱 검정 결과
    print(f"\n카이제곱 검정 결과:")
    print(f"Chi-squared: {chi2:.4f}, p값: {p:.4f}, 자유도: {dof}")
    print(f"결론: {'두 변수 간 연관성이 있음' if p < alpha else '두 변수 간 연관성이 없음'}")
    
    # 효과 크기 계산(크래머의 V)
    n = contingency_table.sum().sum()
    cramers_v = np.sqrt(chi2 / (n * min(contingency_table.shape[0]-1, contingency_table.shape[1]-1)))
    print(f"\n크래머의 V(효과 크기): {cramers_v:.4f}")
    print(f"해석: {'강한 연관성' if cramers_v > 0.25 else '중간 연관성' if cramers_v > 0.15 else '약한 연관성'}")
    
    return "카이제곱 검정", p
```

```python
def time_series_analysis(time_series, seasonal_period=None):
    # 시계열 시각화
    plt.figure(figsize=(12, 6))
    plt.plot(time_series)
    plt.title('시계열 데이터')

    is_stationary = adf_result[1] < 0.05
    print(f"결론: {'시계열이 정상적임' if is_stationary else '시계열이 비정상적임'}")
    
    # 비정상 시계열이면 차분
    if not is_stationary:
        diff_series = np.diff(time_series)
        print("\n1차 차분 후:")
        adf_result_diff = adfuller(diff_series)
        print(f'ADF 통계량: {adf_result_diff[0]:.4f}, p-값: {adf_result_diff[1]:.4f}')
        is_stationary_diff = adf_result_diff[1] < 0.05
        print(f"결론: {'차분 후 정상적임' if is_stationary_diff else '차분 후에도 비정상적임'}")
        
        # 시각화 - 원본과 차분 비교
        plt.figure(figsize=(12, 8))
        plt.subplot(2, 1, 1)
        plt.plot(time_series)
        plt.title('원본 시계열')
        plt.subplot(2, 1, 2)
        plt.plot(diff_series)
        plt.title('1차 차분 시계열')
        plt.tight_layout()
        
        # 분석용 시계열 선택
        analysis_series = diff_series if is_stationary_diff else time_series
        d = 1 if is_stationary_diff else 0
    else:
        analysis_series = time_series
        d = 0
    
    # ACF/PACF 플롯
    plt.figure(figsize=(12, 8))
    plt.subplot(2, 1, 1)
    plot_acf(analysis_series, lags=30, ax=plt.gca())
    plt.title('ACF')
    
    plt.subplot(2, 1, 2)
    plot_pacf(analysis_series, lags=30, ax=plt.gca())
    plt.title('PACF')
    plt.tight_layout()
    
    # ACF/PACF 해석 및 ARIMA 차수 제안
    print("\nACF/PACF 패턴에 기반한 모형 제안:")
    # 여기에 패턴 해석 로직 추가
    
    # 계절성이 있는 경우 SARIMA 고려

    # 여러 모형 적합 및 비교(AIC, BIC)
    print("\n여러 ARIMA 모형 비교:")
    best_aic = float('inf')
    best_model = None
    
    orders = [(1,d,0), (0,d,1), (1,d,1), (2,d,0), (0,d,2), (2,d,2)]
    results = []
    
    for order in orders:
        try:
            if seasonal_period:

                for seasonal_order in seasonal_orders:

                                                     order=order, 
                                                     seasonal_order=seasonal_order)

                    model_name = f"SARIMA{order}{seasonal_order}"
                    results.append({
                        'model': model_name,
                        'AIC': result.aic,
                        'BIC': result.bic
                    })
                    if result.aic < best_aic:
                        best_aic = result.aic
                        best_model = model_name
            else:
                # ARIMA 모형
                model = ARIMA(time_series, order=order)
                result = model.fit()
                model_name = f"ARIMA{order}"
                results.append({
                    'model': model_name,
                    'AIC': result.aic,
                    'BIC': result.bic
                })
                if result.aic < best_aic:
                    best_aic = result.aic
                    best_model = model_name
        except:
            continue
    
    # 결과 출력
    results_df = pd.DataFrame(results).sort_values('AIC')
    print(results_df)
    print(f"\n최적 모형(AIC 기준): {best_model}")
    
    return best_model, d, seasonal_period
```

## 9. ADP 핵심 문제 유형 접근 전략

### 9.1 불량률 차이 검정 문제
1. **데이터 이해**: 각 공장/집단별 불량품 데이터 특성 파악
2. **가설 설정**:
    - H₀: 공장 A와 B의 불량률은 동일하다 (pA = pB)
    - H₁: 공장 A와 B의 불량률은 다르다 (pA ≠ pB)
3. **검정 선택**:
    - 대표본 → 비율 차이 검정(Z-검정)
    - 소표본 → 피셔의 정확검정
4. **결과 해석**: p-value와 유의수준 비교, 결론 도출

### 9.2 지연시간 분포 검정 문제
1. **데이터 이해**: 지연시간 분포 특성 파악(히스토그램)
2. **가설 설정**:
    - H₀: 지연시간 발생 빈도는 포아송분포를 따른다
    - H₁: 지연시간 발생 빈도는 포아송분포를 따르지 않는다
3. **검정 방법**:
    - λ(평균 발생률) 추정
    - 관측빈도와 기대빈도 계산
    - 카이제곱 적합도 검정 수행
    - K-S 검정 수행(대안)
4. **결과 해석**: p-value와 유의수준 비교, 결론 도출

### 9.3 호선별 지연정도 차이 검정 문제
1. **데이터 이해**: 호선별 지연정도 교차표 작성
2. **가설 설정**:
    - H₀: 호선별 지연정도 분포는 동일하다
    - H₁: 호선별 지연정도 분포는 다르다
3. **검정 선택**:
    - 카이제곱 독립성/동질성 검정
    - 기대빈도 5 미만 비율 확인
4. **결과 해석**: p-value와 유의수준 비교, 결론 도출

### 9.4 시계열 모형 식별 문제
1. **데이터 이해**: 시계열 그래프, 추세, 계절성 확인
2. **정상성 검정**: ADF 검정, 필요시 차분
3. **ACF/PACF 분석**:
    - AR 패턴: ACF 서서히 감소, PACF 절단
    - MA 패턴: ACF 절단, PACF 서서히 감소
    - ARMA 패턴: 둘 다 서서히 감소
4. **모형 식별**:
    - ARIMA(p,d,q) 또는 SARIMA(p,d,q)(P,D,Q)s 모형 제안
    - AIC, BIC로 최적 모형 선택

### 9.5 회귀 가정 검토 문제
1. **데이터 이해**: 변수 간 관계 탐색(산점도)
2. **회귀모형 적합**: OLS 등 적절한 회귀분석 수행
3. **가정 검토**:
    - 선형성: 잔차 vs 적합값 플롯
    - 정규성: Q-Q 플롯, Shapiro-Wilk 검정
    - 등분산성: BP 검정, 잔차 vs 적합값 플롯
    - 독립성: Durbin-Watson 검정
    - 다중공선성: VIF 계산
4. **문제점 식별 및 해결방안 제시**:
    - 변수 변환, 이상치 제거, 다른 회귀모형 등
