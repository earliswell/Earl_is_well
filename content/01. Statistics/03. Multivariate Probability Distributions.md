## Bivariate and Multivariate Probability Distributions
- Bivariate : 두 개의 확률 변수를 동시에 고려하는 분포![[Pasted image 20241123140630.png]]
	- 예를 들어, 동전의 앞 뒤를 예로 들었을 때
		- 1. 첫 동전의 결과 (H, T) 
		- 2. 동전의 결과 (H, T)
		- 총 4가지의 경우의 수가 존재
- Multivariate : 셋 이상의 확률 변수를 동시에 고려하는 분포이다.
	- 위와 같은 예를 들자면, 총 3번 이상의 동전을 던져 나오는 경우의 확률분포 표를 의미한다.

**DEFINITION 5.1**
- Let $Y_1$ and $Y_2$ be discrete random variables. The joint (or bivariate) probability function for $Y_1$ and $Y_2$ is given by $$p(y_1, y_2) = P(Y_1=y_1, Y_2=y_2), \qquad -\infty < y_1 < \infty, \, -\infty < y_2 < \infty.$$

**THEOREM 5.1**
- If $Y_1$ and $Y_2$ are discrete random variables with joint probability function $p(y_1, y_2)$, then
	1. $p(y_1, y_2) \geq 0$ for all $y_1, y_2$
	2. $\sum_{y_1, y_2} p(y_1, y_2) = 1$, where the sum is over all values $(y_1, y_2)$ that are assigned nonzero probabilities.

- As in the univariate discrete case, the joint probability function for discrete random variables is sometimes called the joint probability mass function.
	- univariate discrete case : 일변량 이산형 확률분포
		- 단일 변수 (한 개의 변수)를 다루는 경우이다. $\to$ 주사위 한 번 굴렸을 때 나오는 분포
##### 참고, [[Univariate와 Bivariate의 관계]]

**DEFINITION 5.2**
- For any random variables $Y_1$ and $Y_2$, the joint (bivariate) distribution function $F(y_1, y_2)$ is $$F(y_1, y_2) = P(Y_1 \leq y_1, Y_2 \leq y_2), \qquad -\infty<y_1<\infty, \, -\infty<y_2<\infty.$$
	- for Discrete Case.$$F(y_1, y_2) = \sum_{t_1\leq y_1}\sum_{t_2 \leq y_2}p(t_1, t_2)$$
	- For Continuous Case.$$F(y_1, y_2) = \int_{-\infty}^{y_1}\int_{-\infty}^{y_2}f(t_1,t_2)dt_2dt_1$$
	- for all $-\infty < y_1 < \infty, \, -\infty < y_2 < \infty$
- then $Y_1$ and $Y_2$ are said to be jointly continuous random variables. the function $f(y_1, y_2)$ is called the joint probability density function.

**THEOREM 5.2**
- If $Y_1$ and $Y_2$ are random variables with joint distribution function $F(y_1, y_2)$, then 
	1. $F(-\infty, -\infty) = F(-\infty, y_2) = F(y_1, -\infty) = 0$
	2. $F(\infty, \infty) = 1$
		- $F(\infty, \infty) \equiv \lim_{y_1\to\infty}\lim_{y_2\to\infty}F(y_1, y_2) = 1$
	3. if $y_1^* \geq y_1$ and $y_2^* \geq y_2$, then $F(y_1^*, y_2^*) - F(y_1^*, y_2) - F(y_1, y_2^*) + F(y_1, y_2) \leq 0.$ ![[Pasted image 20241123143756.png]]
- 위 1번 특징은 CDF의 특징을 이해하면 쉽다. Joint CDF에서 한 변수가 음의 무한대의 수라면, 이는 다른 변수가 아무리 특정 수를 갖는다고 해도 우리는 어떠한 누적 값을 획득할 수 없다. 
	- 예를 들어 Discrete Case에서, $F(-\infty, y_2) = \sum_{t_1\leq -\infty}\sum_{t_2 \leq y_2}p(t_1, t_2) = 0$인 것 처럼, 일 변수가 음의 무한대인 경우는 존재하지 않음. 
	- 이와 더불어 Continuous Case에서도 $\int_{-\infty}^{-\infty}$인  상한과 하한이 같은 경우의 적분 값은 0이된다. 

**THEOREM 5.2**
- If $Y_1$ and $Y_2$ and jointly continuous random variables with a joint density function given by $f(y_1, y_2)$, then
	1. $f(y_1, y_2) \geq 0$ for all $y_1, y_2$
	2. $\int_{-\infty}^{\infty}\int_{-\infty}^{\infty}f(y_1, y_2)dy_1dy_2 = 1$

## Marginal and Conditional Probability Distributions
- 우리가 주사위를 2번 던지는 경우에 대해서 생각해보자
	- $Y_1 =$ Number of dots on the upper face of die 1
	- $Y_1 =$ Number of dots on the upper face of die 2
	- 이는 각 케이스에서 주사위를 굴렸을 때 하늘을 바라보는 수를 의미한다.

- 그렇다면 $P(Y_1 = y_1) = p_1(y_1)$은 어떻게 구할 수 있을까?
	- 답은 $\sum_{y_2=1}^6 p(y_1, y_2)$이다. 즉, 한 변수를 고정한 후 나머지 경우 확률을 더해주면 된다.
		- y_1이 1인 경우 : y_1이 1이면서 y_2의 범위가 1부터 6까지의 모든 경우의 확률

- 한 축을 고정시켜 놓고 확률을 구할 수 있는데,
	- For Discrete case (Marginal Probability functions of $Y_1, Y_2$)$$p_1(y_1) = \sum_{\text{all}\,y_2}p(y_1, y_2) \qquad \text{and} \qquad p_2(y_2) = \sum_{\text{all}\,y_1}p(y_1,y_2)$$
	- For Continuous case (Marginal density functions of $Y_1, Y_2$)$$f_1(y_1) = \int_{-\infty}^\infty f(y_1, y_2)dy_2 \qquad \text{and} \qquad f_2(y_2) = \int_{-\infty}^{\infty}f(y_1, y_2)dy_1$$
- 우리는 $P(A)$를 unconditional of A 그리고 $P(B|A)$를 probability of B given that A. 즉, Conditional probability라고 부른다.

**DEFINITION 5.5**
- For Conditional Discrete Probability function of $Y_1$ given $Y_2$ $$p(y_1|y_2) = P(Y_1=y_1|Y_2=y_2) = \frac{P(Y_1=y_1, Y_2=y_2)}{P(Y_2 =y_2)} = \frac{p(y_1, y_2)}{p_2(y_2)}$$
	- provided that $p_2(y_2) > 0$

- For Conditional Distribution function(jointly continuous random variable with joint density function) of $Y_1$ given $Y_2 =y_2$ $$F(y_1|y_2) = P(Y_1 \leq y_1|Y_2=y_2)$$
	- $F(y_1) = \int_{-\infty}^\infty F(y_1|y_2)f_2(y_2)dy_2$
		- = $\int_{-\infty}^{y_1}f_1(t_2)dt_1 = \int_{-\infty}^{y_1}\left[\int_{-\infty}^\infty f(t_1, y_2)dy_2\right]dt_1$
		- = $\int_{-\infty}^{\infty}\int_{-\infty}^{y_1}f(t_1, y_2)dt_1dy_2.$
	- $F(y_1|y_2)f_2(y_2) = \int_{-\infty}^{y_1}f(t_1,y_2)dt_1$
		- $F(y_1|y_2) = \int_{-\infty}^{y_1}\frac{f(t_1, y_2)}{f_2(y_2)}dt1.$

- 식을 전개했을 때 ![[Pasted image 20241123154624.png]]
	- 적분 순서를 변경해도 상관 없음 !
	- 주의해야하는 경우
		1. 적분 범위가 변수의 의존할 때
		2. 불연속점이 있는 경우
		3. 무한대 적분의 경우 수렴성을 확인할 필요가 있음.

**DEFINITION 5.7**
- Let $Y_1$ and $Y_2$ be jointly continuous random variables with joint density $f(y_1, y_2)$ and marginal densities $f_1(y_1)$ and $f_2(y_2)$, respectively. For any $y_2$ such that $f_2(y_2) >0$, the conditional density of $Y_1$ given $Y_2 = y_2$ is given by$f(y_1|y_2) = \frac{f(y_1, y_2)}{f_2(y_2)}$ and for any $y_1$ such that $f_1(y_2) > 0$, the conditional density of $Y_2$ given $Y_1=y_1$ is given by $f(y_2|y_1)=\frac{f(y_1, y_2)}{f_1(y_1)}$

- 항상 분모가 0이 되는 Case를 유의해야한다.

## Independent Random Variable
- 기본적으로 독립 관계라는 것은 하나의 사건이 다른 사건에 영향을 미치지 않는다는 것을 의미하며 수식적으로 풀어내 보자면 $P(A, B) = P(A)P(B)$로 나태낸다.

**DEFINITION 5.8**
- Let $Y_1$ have distribution function $F_1(y_1)$, $Y_2$ have distribution function $F_2(y_2)$, and $Y_1$ and $Y_2$ have joint distribution function $F(y_1, y_2)$. Then $Y_1$ and $Y_2$ are said to be independent if and only if $F(y_1, y_2) = F_1(y_1)F_2(Y_2)$ for every pair real number $(y_1, y_2)$. 
- If $Y_1$ and $Y_2$ are not independent, they are said to be dependent.
	- For Discrete case $p(y_1, y_2) = p_1(y_1)p_2(y_2)$
	- For Continuous case $f(y_1, y_2) = f_1(y_2)f_2(y_2)$

- Definition 5.8은 n차원으로 확장시키기 쉬운 개념이다.$$F(y_1, y_2, \dots, y_n) = F_1(y_1)\cdots F_n(y_n)$$

**THEOREM 5.5**
- Let $Y_1$ and $Y_2$ have a joint density $f(y_1, y_2)$ that is positive if and only if $a \leq y_1 \leq b$ and $c \leq y_2 \leq d$, for constants a, b, c and d; and $f(y_1, y_2) = 0$ otherwise. Then $Y_1$ and $Y_2$ are independent random variables if and only if $f(y_1, y_2) = g(y_1)h(y_2)$ where $g(y_1)$ is a nonnegative function of $y_1$ alone and $h(y_2)$ is a nonnegative function of $y_2$ alone.

## The Expected Value of a Function of Random Variables
- You need only construct the multivariate analogue to the univariate situation to justify the following definition. 
- 즉, univariate에서 확장하면 multivariate에 적용할 수 있음을 의미하고 있다.

**DEFINITION 5.9**
- Let $g(Y_1, Y_2, \dots, Y_k)$ be a function of the discrete random variables, $Y_1, Y_2, \dots, Y_k$ which have probability function $p(y_1, y_2, \dots, y_k)$. Then the expected value(기댓값, 모집단) of $g(Y_,1 Y_2, \dots, Y_k)$ is $$E[g(Y_1, Y_2, \dots, Y_k)] = \sum_{\text{all}\,y_k}\cdots\sum_{\text{all}\,y_2}\sum_{\text{all}\,y_1}g(y_1,y_2, \dots,y_k)p(y_1,y_2,\dots,y_k)$$
- For Continuous Case$$E[g(Y_1, Y_2, \dots, Y_k)] = \int_{-\infty}^\infty\cdots\int_{-\infty}^\infty\int_{-\infty}^\infty g(y_1, y_2, \dots,y_k)\times f(y_1, y_2, \dots, y_k)dy_1dy_2\dots dy_k$$
#### Special Theorems
- Let c be a constant. Then $E(c) = c$
- Let $g(Y_1, Y_2)$ be a function of the random variables $Y_1$ and $Y_2$ and let $c$ be a constants. Then $E[c(g(Y_1, Y_2)] = cE[g(Y_1, Y_2)]$
- Let $Y_1$ and $Y_2$ be random variables and $g_1(Y_1, Y_2), g_2(Y_1,Y_2), \dots, g_k(Y_1, Y_2)$ be functions of $Y_1$ and $Y_2$. Then$$E[g_1(Y_1, Y_2)+g_2(Y_1,Y_2)+\cdots+g_k(Y_1,Y_2)] = E[g_1(Y_1, Y_2)] + E[g_2(Y_1,Y_2)] +\cdots+E[g_k(Y_1,Y_2)]$$
**THEOREM 5.9**
- Let $Y_1$ and $Y_2$ be independent random variables and $g(Y_1)$ and $h(Y_2)$ be functions of only $Y_1$ and $Y_2$, respectively. Then$$E[g(Y_1)h(Y_2)] = E[g(Y_1)]E[h(Y_2)],$$ provided that the expectations exist.

**Proof**
- Assume $Y_1$ and $Y_2$ are independent,
$$\begin{align} E[g(Y_1)h(Y_2)] & = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} g(y_1)h(y_2)f(y_1, y_2)dy_2dy_1 \\ & =\int_{-\infty}^{\infty} \int_{-\infty}^{\infty} g(y_1)h(y_2)f_1(y_1)f_2(y_2)dy_2dy_1 \\ & = \int_{-\infty}^{\infty} g(y_1)f_1(y_1)\left[\int_{-\infty}^{\infty} h(y_2)f_2(y_2)dy_2\right]dy_1 \\ & = \int_{-\infty}^{\infty} g(y_1)f_1(y_1)E[h(Y_2)]dy_1 \\ & = E[h(Y_2)]\int_{-\infty}^{\infty} g(y_1)f_1(y_1)dy_1 = E[g(Y_1)]E[h(Y_2)]\end{align} $$

## The Covariance of Two Random Variables
- Intuitively, We think of the dependence of two random variables $Y_1$ and $Y_2$ as implying that one variable-say,
	- $Y_1$ either increases or decreases as $Y_2$ changes.
- 두 변수의 상관성을 분석하는 데 유용한 개념이다.![[Pasted image 20241123165333.png]]
- 우리는 expectation of $(Y_1 - \mu_1)(Y_2 - \mu_2)$를 구하면 두 변수의 선형 독립(dependence) 혹은 종속(independence) 관계를 확인할 수 있다. 우리는 위 expectation을 covariance라고 부른다.

**DEFINITION 5.10**
- If $Y_1$ and $Y_2$ are random variables with means $\mu_1$ and $\mu_2$, respectively, the covariance of $Y_1$ and $Y_2$ is $$Cov(Y_1, Y_2) = E[(Y_1-\mu_1)(Y_2-\mu_2)]$$
- 우리는 이를 통해서 선형 독립, 종속 관계를 파악할 수 있다.
- 또한, $$\rho = \frac{Cov(Y_1, Y_2)}{\sigma_1\sigma_2}$$ 공분산에서 각 표준편차std로 나눠주면 rho 즉, corrleation(상관관계)를 파악할 수 있다.
	- $\rho$는 $-1\leq \rho \leq 1$의 범위를 갖으며, 양수에서 1에 가까울 수록 양의 상관성이 강해지며, 음수에서 -1에 가까울 수록 음의 상관성이 강해진다.

**THEOREM 5.10**
- If $Y_1$ and $Y_2$ are random variables with means $\mu_1$ and $\mu_2$, respectively, then$$Cov(Y_1,Y_2) = E[(Y_1-\mu_1)(Y_2-\mu_2)] = E(Y_1Y_2)-E(Y_1)E(Y_2)$$
**Proof**
$$\begin{align} Cov(Y_1,Y_2) &= E[(Y_1-\mu_1)(Y_2-\mu_2)] \\ &= E(Y_1Y_2 - \mu_1Y_2 - \mu_2Y_1 + \mu_1\mu_2) \\ &= E(Y_1Y_2) - \mu_1E(Y_2) - \mu_2E(Y_1) +\mu_1\mu_2\end{align}$$ Because $E(Y_1) = \mu_1$ and $E(Y_2) = \mu_2$, it follows that $$Cov(Y_1, Y_2) = E(Y_1Y_2) - E(Y_1)E(Y_2) = E(Y_1Y_2)-\mu_1\mu_2$$

**THEOREM 5.11**
- If $Y_1$ and $Y_2$ are independent random variables, then $Cov(Y_1,Y_2)=0$.
- Thus, independent random variables must be uncorrelated.

- 하지만 주의해야 할 점이 있다. 만약 두 변수의 관계가 independent라면 공분산(Covariance)는 0이 되지만, 공분산이 0이라 해서 무조건 independent관계에 있는 것은 아니다.
	- 즉, 위 이론의 역이 성립되지 않는다. ![[Pasted image 20241123170714.png]]![[Pasted image 20241123170721.png]]

## The Expected Value and Variance of Linear Functions of Random Variables
- In later chapters in this text, especially Chapter 9 and 11, we will frequently encounter parameter estimators that are linear functions of the measurements in a sample, $Y_1, Y_2, \dots, Y_n$. 
- If $a_1, a_2, \dots, a_n$ are constants(상수, we will need to find the expected value and variance of linear function of random variables $Y_1, Y_2, \dots, Y_n$$$U_1 = a_1Y_1+a_2Y_2 +\cdots+a_nY_n=\sum_ia_iY_i$$
- 위를 이해해보자면 우리는 추후 회귀 분석 공부를 하며 위와 같은 형태의 데이터들을 많이 접할 것이다. $U_1$은 어떻게 보면 우리가 직접 겪어야 할 데이터프레임의 한 형태와도 같다. 이는 추후에 더욱 이야기를 적어나가도록 하겠다.

**THEOREM 5.12**
- Let $Y_1, Y_2, \dots, Y_n$ and $X_1, X_2, \dots, Y_m$ be random variables with $E(Y_i) = \mu_i$ and $E(X_j) = \xi_j$. Define$$U_1 = \sum_ia_iY_i \quad \text{and} \quad U_2=\sum_jb_jX_j$$ for constants $a_1, a_2, \dots, a_n$ and $b_1, b_2, \dots, b_m$. Then the following hold:
	1. $E(U_1) = \sum_ia_i\mu_i$$$\begin{align} E(U_1) & = E(\sum_ia_iY_i) \\ & = E(a_1Y_1) + E(a_2Y_2) + \cdots + E(a_nY_n) \\ & = a_1E(Y_1) + a_2E(Y_2) + \cdots + a_nE(Y_n) \\ & = \sum_ia_i\mu_i\end{align}$$
	2. $V(U_1) = \sum_ia_i^2V(Y_i) + 2\sum\sum_{1\leq i<j\leq n}a_ia_j(Cov(Y_i, Y_j)$ where the double sum is over all pairs $(i, j)$ with $i < j$.$$\begin{align} V(U_1) & = E[U_1 - E(U_1)]^2 = E\left[\sum_ia_iY_i - \sum_ia_i\mu_i\right]^2 \\ &= E\left[\sum_ia_i(Y_i-\mu_i)\right]^2 \\ &= E\left[\sum_ia_i^2(Y_I-\mu_i)^2 + \sum_i\sum_ja_ia_j(Y_i-\mu_i)(Y_j-\mu_j)\right] \quad where  \, i\neq j\end{align}$$
	3. $Cov(U_1, U_2) = \sum_i\sum_ja_ib_jCov(Y_i, X_j)$.
- $U_1$ : $Y_i$에 대한 weighted sum
- $U_2$ : $X_j$에 대한 weighted sum

## The Multinomial Probability Distribution
- [[Binomial]]은 2가지 True/False와 같은 이진으로 나눠지는 경우의 Case를 다뤘다.
- Multinomial Probability Distribution은 이진으로 나눠지는 것이 아닌 k개의 classes인 경우를 다루는 확룰분포표를 의미한다.

**DEFINITION 5.11**
- A multinomial experiment possesses the following properties:
	1. The experiment consists of $n$ identical trials
	2. The outcome of each trial falls into one of $k$ classes or cells.
	3. The probability that the outcome of a single trial falls into cell $i$, is $p_i$, $i = 1, 2, \dots, k$ and remains the same from trial to trial. Notice that $p_1 + p_2 + \dots + p_k = 1$
	4. The trials are independent.
	5. The random variables of interest are $Y_1, Y_2, \dots, Y_k$, where $Y_i$ equals the number of trials for which the outcome falls into cell $i$. Notice that $Y_1 + Y_2 + Y_3 + \dots + Y_k = n$

**Joint Probability function for $Y_1, Y_2, \dots, Y_k$ is given by**$$p(y_1, y_2, \dots, y_k) = \frac{n!}{y_1!y_2!\cdots y_k!}p_1^{y_1}p_2^{y_2}\cdots p_k^{y_k} \qquad \text{where} \qquad \sum_ip_i=1 \quad \text{and} \quad \sum_iy_i=n$$

**THEOREM 5.13**
- If $Y_1, Y_2, \dots, Y_k$ have a multinomial distribution with parameters $n$ and $p_1, p_2, \dots, p_k$, then
	1. $E(Y_i) = np_i, \quad V(Y_i)=np_iq_i$
		- $E(Y_1) = \sum_{y_1}\sum_{y_2}\cdots\sum_{y_k}y_1\frac{n!}{y_1!y_2!\cdots y_k!}p_1^{y_1}p_2^{y_2}\cdots p_k^{y_k}$
	2. $Cov(Y_s, Y_t) = -np_sp_t, \quad \text{if} s\neq t$

## Conditional Expectations
- Conditional expectations are defined in the same manner as univariate expectations except that conditional densities and probability functions are used in place of their marginal counterparts.

**DEFINITION 5.13**
- If $Y_1$ and $Y_2$ are any two random variables, the conditional expectation of $g(Y_1)$ given that $Y_2 = y_2$, is defined to be$$E(g(Y_1)|Y_2=y_2) = \int_{-\infty}^\infty g(y_1)f(y_1|y_2)dy_1$$
- if $Y_1$ and $Y_2$ are jointly continuous and$$E(g(Y_1)|Y_2=y_2) = \sum_{\text{all}\,y_1}g(y_1)p(y_1|y_2)$$
- if $Y_1$ and $Y_2$ are jointly discrete.

**THEOREM 5.14**
- Let $Y_1$ and $Y_2$ denote random variables. Then $$E(Y_1)=E[E(Y_1|Y_2)]$$
- Proof$$\begin{align} E(Y_1) &= \int_{-\infty}^\infty\int_{-\infty}^\infty y_1f(y_1, y_2)dy_1dy_2 \\ & = \int_{-\infty}^\infty\int_{-\infty}^\infty y_1f(y_1|y_2)f_2(y_2)dy_1dy_2 \\ &= \int_{-\infty}^\infty\left\{\int_{-\infty}^\infty y_1f(y_1|y_2)dy_1\right\}f_2(y_2)dy_2 \\ &=\int_{-\infty}^\infty E(Y_1|Y_2=y_2)f_2(y_2)dy_2 = E[E(Y_1|Y_2)]\end{align}$$
- 즉 Expectation of Conditional Expectation은 Expectation과 같다.

**THEOREM 5.15**
- Let $Y_1$ and $Y_2$ denote random variables. Then$$V(Y_1) = E[V(Y_1|Y_2)] + V[E(Y_1|Y_2)]$$
- Proof 
	1. $V(Y_1|Y_2) = E(Y_1^2|Y_2) - [E(Y_1|Y_2)]^2$
	2. $E[V(Y_1|Y_2)] = E[E(Y_1^2|Y_2)] - E{[E(Y_1|Y_2)]^2}$
	3. BY definition, $V[E(Y_1|Y_2)] = E\{[E[Y_1|Y_2]^2\}-\{E[E(Y_1|Y_2)]\}^2$$$\begin{align} V(Y_1) &= E[Y_1^2] - [E(Y_1)]^2 \\ &= E\{E[Y_1^2|Y_2]\} - \{E[E(Y_1|Y_2)]\}^2 \\ &= E\{E[Y_1^2|Y_2]\} - E\{[E(Y_1|Y_2)]^2\} + E\{[E(Y_1|Y_2)]^2\} - \{E[E(Y_1|Y_2]\}^2 \\ &= E[V(Y_1|Y_2)] + V[E(Y_1|Y_2)].\end{align}$$

- the mean and variance of a random variable can be used with [[Tchebysheff's Theorem]] to provide bounds for probabilities when the distribution of the variable is unknown or difficult tor derive.
- 이는 결국 다음을 의미한다. 일반적으로 확률 분포를 알아야 확률을 계산할 수 있는데 우리는 Tchebysheff's 이론을 통해서 최소한의 확률 분포 정보를 획득해서 분포를 알지 못하더라도 평균과 분산의 범위를 예측할 수 있다는 의미를 갖는다.
