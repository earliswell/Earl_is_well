## Problem

Write a solution to find the daily active user count for a period of `30` days ending `2019-07-27` inclusively. A user was active on someday if they made at least one activity on that day.

Return the result table in **any order**.

The result format is in the following example.


## My Answer.
```python
import pandas as pd

def user_activity(activity: pd.DataFrame) -> pd.DataFrame:
	
	# 날짜 범위 설정
	end_date = '2019-07-27'
	start_date = pd.to_datetime(end_date) - pd.Timedelta(days=29)
	
	# 날짜 필터링
	mask = (activity['activity_date'] >= start_date) & (activity['activity_date'] <= end_date)
	filtered_activity = activity[mask]
	
	# 일별 고유 사용자 수 계산
	daily_active = (filtered_activity.groupby('activity_date')['user_id'].nunique()
	.reset_index().rename(columns={'activity_date': 'day', 'user_id': 'active_users'}))
	
	return daily_active
```
