## Problem

Write a solution to:

- Find the name of the user who has rated the greatest number of movies. In case of a tie, return the lexicographically smaller user name.
- Find the movie name with the **highest average** rating in `February 2020`. In case of a tie, return the lexicographically smaller movie name.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def movie_rating(movies: pd.DataFrame, users: pd.DataFrame, movie_rating: pd.DataFrame) -> pd.DataFrame:
	many_rate = movie_rating.groupby(['user_id'])[['rating']].count().reset_index()
	user_name = users.merge(many_rate[many_rate['rating'] == many_rate['rating'].max()]).sort_values('name').iloc[0, 1]
	
	movies_rate = movies.merge(movie_rating[(movie_rating['created_at'] >= '2020-02-01') & (movie_rating['created_at'] <= '2020-02-28')].groupby(['movie_id'])[['rating']].mean().reset_index()).sort_values('title')
	movie_name = movies_rate[movies_rate['rating'] == movies_rate['rating'].max()].iloc[0, 1]
	
	return pd.DataFrame({'results': [user_name, movie_name]})
```
