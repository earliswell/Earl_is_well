## Source-Free Active Domain Adaptation
- 소스 데이터가 없음.(모델 한 번 학습하고 이후 사용하지 않음)
- 이후 데이터에 라벨을 붙일지를 결정하는 ?

### 한계점
- 소스 데이터가 없는데 → 타겟 샘플을 어떻게 선택?
- 소스 데이터의 분포를 참조 불가 → 차이를 어떻게 줄임?
- Active Learning을 반복 → 지속적 성능 향상을 보장함 ?
- 소스 데이터를 직접 접근한다

## 제안 방법론
- SFADA: 쿼리 단계와 라벨링 단계를 반복 → 오류를 최소화
- 어떻게 정보성을 높은 샘플을 선택?
### LFTL
- 소스 모델과 능동적 반복 업데이트 되는 모델의 무엇을 보완하고 어디를 adaptation을 보완 ?
#### CAS
- 이전 모델의 예측을 이용해서 → 새로운 정보를 담고 있는 것을 선별함
#### VPA
- 소스 도메인 학습 특징을 → 이전 단계의 특징을 보존 도메인 정렬을 도와줌. 

### CAS
- 콘트라스티브 디코딩 → 현재 모델과 이전 모델의 예측을 비교함 ?
	- 현재 모델이 이전 모델보다 샘플에 대한 확신을 갖고 있다면 → 이미 학습된 지식
	- 반대는 → 새로운 지식(이를 더욱 라벨링할 필요가 있음.)
- 샘플 선택 기준
- BvSB : 모델이 가장 혼동하는 클래스를  → 두 값이 작을 수록 (모델이 구분하는 데 어려움을 겪음)
- Class Transferability : 맑은 날의 풍경 사진 모델 → 흐린 날에 풍경 사진에 적용 (하늘: 파란/회색) 모델이 혼동하기 쉬움 / 나무는 대체로 녹색으로 나타나 덜 혼동됨. → 도메인 이동이 더 취약한 클래스 우선 선택
- Temporal Stagnancy : 지속적으로 어려운 샘플들을 포착함.

### VPA
- 초기 단계에서 라벨링된 데이터를 통해서 학습을 진행 ?
- 라벨링된 타겟 데이터에 대해서 정답을 잘 맞추도록 함.
- 앵커 기반 클러스터링: 라벨링된 샘플에 가깝게 진행. 라벨링되지 않은 샘플들이 앵커 주변에 모임 ?
- visual persistence vault: 앵커의 특징을 시간에 따라 유지함. 틸다의 유무가 현재와 이전 모델의 앵커라고 생각하고 기릿 함 $\gamma$는 모멘텀 파라미터 (0.9)

#### VPA loss
- 앵커 기반 클러스터링을 이용해서  → 라벨이 없는 샘플들이 앵커 주변들에 가깝게 모임
#### Entropy minimization loss
- 라벨이 없는 샘플에 대한 예측 확산도를 높여 판별적 특징을 학습.
