## Problem

Write a solution to calculate the number of bank accounts for each salary category. The salary categories are:

- `"Low Salary"`: All the salaries **strictly less** than `$20000`.
- `"Average Salary"`: All the salaries in the **inclusive** range `[$20000, $50000]`.
- `"High Salary"`: All the salaries **strictly greater** than `$50000`.

The result table **must** contain all three categories. If there are no accounts in a category, return `0`.

Return the result table in **any order**.

The result format is in the following example.

## My Answer.
```python
import pandas as pd

def count_salary_categories(accounts: pd.DataFrame) -> pd.DataFrame:
	bins = [-float('inf'),19999, 50000, float('inf')]
	labels = ['Low Salary', 'Average Salary', 'High Salary']
	
	categories = pd.cut(accounts['income'], bins=bins, labels=labels)
	result = categories.value_counts().reindex(labels, fill_value=0).reset_index()
	result.columns = ['category', 'accounts_count']
	
	return result
```
