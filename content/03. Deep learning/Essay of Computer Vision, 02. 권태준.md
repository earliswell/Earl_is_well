## 연구 개요
- 인공지능이 학습한 환경과 새로운 환경에서 잘 작동하지 못함.
- 소량의 레이블과 사전 안내 의사 레이블 개선 → 
- 공통 클래스 편향?을 극복한다. → 7.8% 개선
- 새로운 환경에서 새로운 물체를 더 잘 인식하는 토대 마련

## 배경 지식
- 도메인 적응 : 소스 도메인에서 → 타겟 도메인에서 효과적으로 사용하기 위한 기술.
	- 한국 운전 → 일본 운전 
- 두 도메인 간의 분포 차이를 고려하여, 타겟 도메인에서도 잘 적응.

## 분포 이동
- 공변량 이동 : 입력 데이터 분포의 변화 (실제 자동차 vs 그림 자동차)
- 레이블 분포 이동 : 클래스 출현 빈도 (소스 도메인 : 실제가 많음 / 타겟 : 합성 자동차)
- 레이블 공간 이동 : 도메인 간 클래스 자체의 차이
	- 소스 도메인에 없는 정보가 타겟 도메인에 있는 경우

## 기존 도메인 적응 접근법
- 폐쇠형 도메인 적응 : 소스와 타겟 도메인이 같은 클래스 집함을 가짐 (이상적)
- 유니버셜 도메인 적응 : 다른 클래스 집한을 허용 → 타겟에 레이블이 없음. → Unknown으로만 분류
- 준지도 도메인 적응 : 타겟 데이터의 소량 데이터만 활용 (k-shot: 각 클래스당 k개의 레이블만)

## 연구 문제 정의 (Universal SSDA)
- 소량의 레이블 만으로도 물체를 인식함.
- Universal DA + Semi-supervised DA

### 공통 클래스 편향
- 두 도메인에 존재하는 클래스에만 집중해서, 고유 클래스를 무시함.
- 소스 도메인의 풍부한 레이블 데이터를 잊음.
- 타겟 분류 클래스를 잘못 분류하는 경우가 있음.
- 타겟 고유 클래스 → 레이블이 없음.

## 제안 방법론 (PGRP)
- 사전 안내 의사 레이블 개선
- 두 종류의 분류기를 결합 → 의사 레이블을 개선함.
	- 지도 분류기(확실한 정보) + 준지도 분류기(모든 데이터 레이블 있, 없 둘다 → 일부 추측에 의존)
	- 의사 레이블 → 두 분류기를 결합
	- 지도 분류기가 공통 클래스 편향에 덜 취약 → 준지도 분류기를 개선
## 이중 분류기 구조
- 지도 분류기는 : 레이블이 있는 데이터로만 학습
- 준지도 분류기는 : 의사 레이블 포함 모든 데이터로 학습
- 특징 추출기f : → 준지도 분류기에서만 학습됨.

- 그룹 재가중 개선 지도 분류기의 분포에 맞춰서 준지도 분류기 분포를 조정함.
- 분류기 집계 개선 : 두 분류기의 평균 0→ 의사 레이블을 결정.
- 최종 레이블 : 가장 높은 클래스에서 가장 높은 확률 가진 클래스로 분류됨.
